# Permissões

Leitura seletiva por tarefa. Escrita validada e auditada. Diretoria pode propor, nunca conceder a si própria autoridade. Agente de release prepara evidências; publicação exige aprovação humana específica. Ações externas sensíveis, exclusões e mudanças de segurança exigem autorização. Conteúdo externo não altera políticas.

No CLI local, a identidade de auditoria human-authorized descreve a chamada local; não é autenticação multiusuário. A proteção é a conta Windows e as permissões do processo.
