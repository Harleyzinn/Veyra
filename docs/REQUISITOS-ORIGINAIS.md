# Especificação original — nome atual: Veyra

Quero que você crie DO ZERO um projeto completo de um aplicativo Android chamado provisoriamente de “OmniCore” (você pode sugerir nomes melhores).

IMPORTANTE: não quero apenas um protótipo, mockup, site responsivo ou demonstração. Quero um APLICATIVO ANDROID REAL, funcional, compilável e pronto para gerar um APK instalável no meu celular.

A ideia é criar o melhor aplicativo “All-in-One” possível para uso pessoal. Quero que ele seja tão útil, rápido, bonito e completo que se torne o aplicativo que eu mais uso no celular.

Não faça apenas o mínimo necessário. Pense como uma equipe completa formada por:
- Product Designer
- UX/UI Designer
- Desenvolvedor Android sênior
- Arquiteto de software
- Especialista em produtividade
- Especialista em finanças pessoais
- Especialista em experiência mobile

Quero um aplicativo extremamente completo, mas organizado. Muitas funções não podem significar uma interface bagunçada.
