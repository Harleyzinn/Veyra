# Veyra Finanças 3.0.0

Nova experiência financeira para Android e web instalável no iPhone: saldo confirmado, “Você pode gastar” com explicação, receitas por dia útil, contas, cartões e parcelas, planejamento, relatórios e 24 temas completos.

Dados existentes preservados. O APK usa o pacote e a chave originais. Faça backup antes de atualizar. Configurações → Abrir experiência anterior e conta mantém acesso aos módulos, login e sincronização nativos anteriores.

O web-app usa armazenamento local, funciona offline após o primeiro carregamento e permite exportar/importar JSON e CSV com prévia e deduplicação. No iPhone, abra no Safari e adicione à tela inicial. Não é um aplicativo nativo publicado na App Store. A versão web ainda não sincroniza dados com o Firebase.

Registro automático de receitas e novos alertas funcionam ao abrir o app. Feriados locais e móveis são manuais. Preferências novas são locais por usuário, preservadas no backup; não foram ampliadas regras de segurança do Firebase. Nenhuma integração bancária é necessária.
