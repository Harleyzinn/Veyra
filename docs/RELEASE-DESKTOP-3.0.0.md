# Veyra Life Desktop 3.0.0

Primeira versão Windows do ecossistema Veyra, com o projeto Firebase existente e registros compatíveis com Android. Instale **VeyraLife-Setup-3.0.0.exe** e use a mesma conta Google do celular.

Central personalizável, financeiro com faturas/projeções/simulador, tarefas e Kanban, notas Markdown com autosave e histórico, calendário, hábitos, metas, foco, captura global, busca, mini dashboard, widgets e bandeja Windows. Os 81 tipos de registro existentes permanecem acessíveis por formulários compatíveis.

Cache criptografado com chave protegida pelo Windows, fila offline durável, conflitos explícitos, lixeira, backup compatível com senha opcional e atualizações por manifesto assinado Ed25519/SHA-256. Anexos locais e clipboard opt-in; nenhum envio de dados financeiros para analytics.

Requer Windows 10/11 x64. Esta distribuição não tem certificado Authenticode comercial; SmartScreen pode exibir um aviso de reputação. A assinatura do atualizador verifica futuras versões dentro do aplicativo. Login Google real requer interação do usuário no navegador padrão.

Leia o [guia de instalação e uso](https://github.com/Harleyzinn/Veyra/blob/main/docs/DESKTOP.md) e a [arquitetura](https://github.com/Harleyzinn/Veyra/blob/main/docs/DESKTOP-ARCHITECTURE.md). Atualize também o celular para o [APK 2.2.0](https://github.com/Harleyzinn/Veyra/releases/tag/v2.2.0).
